# XRD1-VR
Virtual Reality Project for XRD1 course at VIA University College (GBE Students)

# 🕰️ Forward to the Past

**Forward to the Past** is a **Virtual Reality (VR) puzzle adventure** built with **Unity** and the **XR Interaction Toolkit**.  
Players travel through **four time-themed rooms**, each representing a distinct period in human history.  
In every room, players face **2–3 interactive puzzles** inspired by the technology and culture of that era.  
Solving these challenges unlocks a **portal** to the next period — moving paradoxically *forward by going back in time.*

---

## ✨ Features
- 🧩 **Era-Based Puzzle Rooms** – four immersive environments: Ancient South America, Ancient China, Ancient Egypt and Ancient Greece.  
- 🕹️ **Interactive VR Mechanics** – grab, inspect, activate, and assemble objects using natural hand interactions.  
- 🌀 **Portal Progression** – unlock new time periods by solving themed puzzles.  
- 🔊 **Dynamic Environments** – each era features unique visuals, lighting, and soundscapes.  
- 📜 **Narrative Layer** – uncover fragments of a story connecting all four timelines.  

---

## 🎯 Motivation
Our goal is to design a VR experience that **blends storytelling, historical atmosphere, and interactive learning**.  
Each puzzle is conceptually tied to its era — reflecting how humans solved problems in different stages of civilization.  
The project encourages **logical reasoning, spatial awareness, and curiosity** while showcasing the potential of VR as an immersive medium.

---

## 🚀 Tech Stack
- **Unity 2022.3 LTS**  
- **XR Interaction Toolkit** (OpenXR backend)  
- **Meta Quest 2 / PCVR compatible**  
- **C#** for interaction and puzzle logic  
- **Blender** for environment and object modeling  
- **Git + Git LFS** for collaboration and version control

## 🛠️ Getting Started

### Prerequisites
- Unity **2022.3 LTS** or higher  
- **Meta Quest 2 / Quest 3** (Standalone or PCVR link)  
- **Git** with **Git LFS** (for large 3D assets)  
- Optional: **Blender** for 3D modeling or edits  

### Installation
```bash
# Clone repository
git clone https://github.com/Samu1311/XRD1-VR.git

# Move into project folder
cd XRD1-VR

# Open in Unity Hub (use Unity 2022.3 LTS)
```
